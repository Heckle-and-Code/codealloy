# Welcome to CodeAlloy

### Where developer intent meets open models

CodeAlloy is a sovereign, open-source AI code editor forked from Code-OSS, built from the ground up for developers who want Cursor-like autonomy powered entirely by local or self-hosted open-weights models.

---

### Core Principles:
- **Built-in Inference Engine:** Native `llama.cpp` with Apple Silicon Metal acceleration embedded directly into the editor. Download and run GGUF models with zero external installations or dependencies.
- **100% Private & Sovereign:** Zero telemetry, zero cloud lock-in. Your code and prompts never leave your local machine or private network.
- **5-Tier Autonomy Dial:** Full developer control over agent authority, from passive assistance (L0) to supervised diff approval (L2) and guarded autonomous multi-file project edits (L3/L4).
- **Shadow Git Checkpoints:** Sub-5ms isolated worktree snapshots before every agent turn, with 1-click turn rollbacks to effortlessly reverse mistakes.
- **Open Model Flexibility:** Use the built-in Metal engine, or connect to existing Ollama, vLLM, and LM Studio endpoints whenever you prefer.
- **Open Ecosystem:** Preconfigured with the Open VSX marketplace for 1-click installation of thousands of extensions.
