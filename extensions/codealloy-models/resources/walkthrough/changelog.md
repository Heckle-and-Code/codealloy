# What's New in CodeAlloy

### Latest Release: v0.1.0-alpha.5

Welcome to the initial developer preview of CodeAlloy! Here are the latest updates and additions:

---

### Key Highlights:
- **Dedicated Welcome Experience:** Native, zero-telemetry onboarding with 1-click model setup and project access.
- **Embedded AI Engine:** Full autonomous tool-calling loop, Agent Chat Webview, Model Selector, and Autonomy Dial bundled natively in all desktop distributions.
- **Standalone CLI Launchers:** Run `alloy .` or `codealloy .` from your terminal to launch projects instantly.
- **Universal macOS DMGs:** Fixed macOS Sonoma APFS compression issues by adopting standard HFS+ disk formatting with Apple `ditto` and ad-hoc codesigning.
- **Shadow Git Time-Travel:** Lightning-fast (<5ms) pre-turn checkpoints and 1-click turn rollbacks.
- **Native Inline Diffs:** Stream multi-line agent edits directly in the editor buffer with single-stroke accept (`Tab`) or discard (`Esc`).
- **Open VSX Marketplace:** Sideload `.vsix` packages or install thousands of open-source extensions with 1 click.
